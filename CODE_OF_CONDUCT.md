# Code of Conduct

This project aims to maintain a respectful, technically serious, and welcoming
environment for users and contributors.

## Expected behavior

- Be respectful in technical discussion and review.
- Focus criticism on ideas, code, and evidence, not on people.
- Assume good faith and ask for clarification before escalating disagreement.
- Share feedback that is specific, actionable, and professional.
- Respect different levels of experience and different use cases.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory language or exclusionary behavior.
- Repeatedly derailing technical discussion.
- Publishing private information without permission.
- Any conduct that makes collaboration unsafe or unreasonably hostile.

## Scope

This code of conduct applies to project discussions, issues, pull requests,
reviews, and other community spaces related to this repository.

## Reporting

If you experience or observe unacceptable behavior, report it privately to the
maintainers through the repository contact channels or by opening a private
communication path with a maintainer.

Maintainers may remove, edit, or reject comments, issues, commits, or pull
requests that violate this code of conduct.
