RL Spin Decoupler
=================

RL Spin Decoupler is a small Python library for synchronizing a reinforcement
learning loop with an external agent loop that runs in another process and may
advance under a different clock.

The documentation is organized around installation, practical use, and the
public API reference generated from the source docstrings.
